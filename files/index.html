🎓 Blockchain Certificate Verification

Industry-Oriented Secure Certificate Issuance & Verification System

⚙️ Step 1: One-time setup

1. Deploy CertificateVerification.sol in Remix IDE to an Ethereum test network (e.g. Sepolia).
2. Copy the deployed contract address and paste it below.
3. Click "Connect MetaMask" (make sure MetaMask is set to the same test network).
See README.md for full step-by-step instructions.

🏫 Admin: Issue Certificate

Only the wallet that deployed the contract can issue certificates.

🔍 Public: Verify Certificate

Anyone can verify — no wallet or gas fee required.
